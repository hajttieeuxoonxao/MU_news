# Changelog 2026-11-01 00:38 — Cập nhật bản vá Expo SDK 58

**Bước trong tài liệu hướng dẫn:** A6 (app Expo)
**Phạm vi thay đổi:** `mu-news-app/`, `docs/command_to_run/04_chay_app.md`

## Tóm tắt

`npx expo start` báo có bản cập nhật Expo. Nhóm chạy trên máy (Windows):

```powershell
npm install expo@~58.0.22
npx expo install --fix
```

Đây là bản vá trong cùng SDK 58 (không đổi SDK), Expo Go vẫn mở được app, không sửa code.
