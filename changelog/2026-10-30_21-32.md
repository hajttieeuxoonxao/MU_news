# Changelog 2026-10-30 21:32 — Bước A2: Dựng server Express và chốt hợp đồng API

**Bước trong tài liệu hướng dẫn:** A2 (Backend 1: Dựng server và chốt hợp đồng API)
**Phạm vi thay đổi:** `backend/`, `docs/`, file gốc

## Tóm tắt

- Khởi tạo `backend/` (Node.js + Express 5 + TypeScript chạy bằng `tsx`), cài thư viện theo đúng danh sách của A2.
- Viết khung trả lời chung `{ status, message, data }`, cache-aside có bản cũ dự phòng, route `/api/health`, server có `helmet`, `cors`, `express-rate-limit`.
- Lưu hợp đồng API vào `docs/report/api-contract.md`.
- Đã chạy thử: `GET /api/health` trả `"status": "success"`; đường dẫn sai trả 404 tiếng Việt; `tsc --noEmit` không lỗi.

## Điểm khác so với tài liệu hướng dẫn

- `config.ts` có sẵn dòng `fplShort: 'MUN'` (tài liệu bảo thêm ở A4) để không phải sửa file này hai lần.
- `tsconfig.json` thêm `"types": ["node"]` vì TypeScript 7 cần khai báo rõ kiểu của Node.js.
- Thư mục `backend/src/` tạo đủ `routes/ services/ adapters/ repositories/ lib/ seed/` và `backend/data/` như cây thư mục ở A2.
